# 3분 시연 동선 (가상 데이터만 사용)

| 시간 | 화면 | 할 일 | 말할 점 |
|---|---|---|---|
| 0:00–0:20 | 사건 목록 | 새 사건 생성 | 모바일 우선, 로컬 시연 |
| 0:20–0:50 | 입력 > 텍스트 | `samples/sample_comments.json`의 댓글 붙여넣기 | 줄 단위 분리, 원문 수정 없음 |
| 0:50–1:15 | 입력 > 이미지 | `sample_screenshot_1.png` 업로드 | 읽지 못한 작성자·시각은 null |
| 1:15–1:30 | 입력 > URL | YouTube URL 조회 (실패 시 안내 문구 보여주기) | 공식 API, 최대 200개 |
| 1:30–2:00 | 댓글 선택 > 분석 | 2개 이상 선택 후 판독 | 3단계, 문제 문구·이유 |
| 2:00–2:20 | 증거함 | 원하는 댓글만 저장 | SHA-256·수집 시각 기록 |
| 2:20–2:35 | 체크리스트 | 누락 항목 답변 저장 | 작성률이지 법적 충분성 아님 |
| 2:35–3:00 | 문서 | 경위서·증거목록 PDF 다운로드 | 사실/AI 추정 분리, 고지 문구 |

예비: 네트워크·API 실패 시 `LLM_PROVIDER=mock`, 샘플 PDF는 `PDF_TEST_OUT=<폴더>`로 미리 생성.
